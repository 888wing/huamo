# 化墨 下一階段規劃（2026-11-15）

三項互相依賴：登頂擊殺要靠化獸，化獸要靠新的跳躍和翻滾，所以建議按「一 → 二 → 三」的次序做，每一項都可以單獨驗收。

沿用現有做法：骨架在程式裡擺姿勢，不用外部動畫檔，體積保持小。每個動作都配一個腳本示範（`?demo=...`）和一項可量度的檢查。

## 一、玩家角色動作

### 現況

人形只有：行走／跑步（同一個循環，前傾固定）、三段連擊、格擋（一個靜止姿勢）、閃避（只是快速平移，沒有姿勢）、受擊（向後仰一下）、倒地（縮小化墨）。沒有跳躍姿勢、沒有落地、沒有受擊方向、沒有死亡動作。

### 做法：把姿勢拆成四層，逐層疊加

| 層 | 內容 | 蓋過下層的方式 |
|---|---|---|
| 移動層 | 站立、走、跑、急停、轉身 | 基底 |
| 空中層 | 起跳、上升、頂點、下落、落地 | 離地時取代腿和軀幹 |
| 動作層 | 斬擊、格擋、閃避 | 取代上半身，閃避取代全身 |
| 反應層 | 受擊、擊飛、起身、死亡 | 取代全部 |

每層輸出一組骨骼目標角度，層與層之間用權重混合。骨骼改用「彈簧跟隨」而不是現在的指數逼近，動作會有過衝和回彈，看起來有重量。

### 逐個動作的規格

**跑步**
- 腳掌著地後釘在地上不動，身體走遠了才提腳邁到下一個落點，腿用反向運動學去夠腳掌。前後左右移動都一樣，所以不會打滑。
- 速度超過約 3 米／秒進入前傾跑：上身前傾約 33 度，左手按著腰間的刀鞘，右手隨步擺動並在高速時收到身後。（實作時改了：刀在鞘裡時「持刀手收在身後、另一手護斗笠」不合理。）
- 轉彎時身體向內側傾；急停時後仰、腳掌剎地、腳邊揚起一小團霧。
- 站立時有呼吸、重心轉移、手按刀柄。

**跳躍**（空白鍵）
- 起跳：0.08 秒下蹲後彈起，雙腿伸直。
- 頂點：收膝，披風和袍腳靠布條模擬自然揚起。
- 下落：雙腿前伸找地。落地：下蹲緩衝 0.12 秒；高處落下改為前滾。
- 按住跳得高，輕按跳得低。空中可微調方向。
- 起跳和落地都會在霧裡吹開一圈。
- **空中按攻擊＝下突刺**：這是第三項擊殺用的動作，在這一項先做好。

**格擋**（右鍵／Q）
- 舉刀有 0.08 秒過渡；格擋中可慢步橫移。
- 擋下：身體被推後 0.5–1 米、手臂吸震、刀上亮屑。
- 彈開（抓準時機）：刀向外一撥，敵人門戶大開，之後 0.6 秒內的斬擊傷害加倍。
- 巨人的掌擋不住：格擋會被打飛。

**迴避**（Shift）
- 不按方向＝後跳：0.3 秒、後移 3.2 米、低弧線、0.05–0.22 秒無敵。
- 按方向＝翻滾：0.42 秒、移動 4.2 米、0.06–0.30 秒無敵。
- 迴避後立刻按攻擊＝衝斬。

**受擊**
- 輕擊：按來向側身縮一下 0.25 秒，斗笠歪。
- 重擊：踉蹌後退 0.5 秒。
- 擊飛（巨掌、震波）：離地翻滾、背部著地、0.6 秒起身（起身期間無敵）；空中按跳可受身直接站穩。

**死亡**
- 最後一擊慢動作 0.4 秒；跪下、刀插地、向前倒。
- 身體化成墨，墨由三維霧帶走；斗笠最後才消失。
- 重生：墨在存檔點聚回人形。

### 驗收
- `?demo=moves`：依次做完全部動作的 20 秒示範，關霧版和開霧版各一段影片。
- 檢查：腳掌打滑量（腳著地期間的水平位移）少於 3 厘米；每個動作的時間和位移與上表相符。

## 二、化獸過渡與獸形骨架

### 操作（按你的想法）

動作進行中再按一次同一個鍵＝化獸。化獸持續 5 秒，畫面出現一條水墨計時條。

| 觸發 | 化成 | 用途 |
|---|---|---|
| 跳躍中再按跳 | 鶴 | 上升、滑翔、越過障礙 |
| 翻滾中再按迴避 | 虎 | 高速衝刺、撲擊、沿斜面奔跑 |
| 格擋中再按格擋 | 鯉 | 潛入霧下、無法被打中、霧中穿行 |

第三行是我補的建議：你只舉了鶴和虎，鯉需要一個觸發。格擋轉潛霧的意思是「以柔克剛」，三種獸剛好分別對應上（鶴）、前（虎）、避（鯉）。

**變回人形**有兩個時機，都帶一招：
- 5 秒用完：原地變回，保留速度。
- 化獸中按攻擊：提早變回並出招。虎＝撲斬；鶴＝下突刺；鯉＝由霧下升起的上挑斬。

**墨量條**（共用一條）：畫面下方一筆橫墨。
- 化獸期間墨由濃到枯、由長到短，像毛筆漸漸寫乾；滿墨可以撐 5 秒，最後 1 秒筆尾飛白閃動。
- 三種獸共用這一條墨。墨量不足三分之一時不能化獸。
- 人形時墨慢慢回濕：8 秒回滿；每斬中一刀額外回一成。
- 提早變回會保留剩下的墨，所以可以「化虎兩秒、變回、再化鶴三秒」這樣分開用，這正是登頂要用的節奏。

數字鍵 1–4 的直接切換保留為除錯用，正式操作只用上面三種。

### 過渡動畫

現在的變身是「原地噴墨、瞬間換模型」。改為順著動作變：

- **跳 → 鶴**：人形收腿蜷身，向上化成一道墨；披風布條張開成翼。0.2 秒內兩個身體同時存在，人形沿脊柱收細，鶴由胸口長出、翼由收到展。起跳的速度直接變成飛行速度。
- **滾 → 虎**：翻滾的蜷身在轉到底時展開成虎的落地撲姿（前爪先著地、脊柱由彎到直），接著起跑。
- **擋 → 鯉**：人形垂直沉入霧面消失，霧面盪開一圈；鯉在霧下游出。
- **變回**：獸身拉長成一道墨，人形由墨的前端衝出並接上對應招式。

### 獸形骨架和動態

**虎**
- 腿由兩節改三節（肩／肘／腕，髖／膝／踝）加腳掌。
- 脊柱四節，奔跑時有收攏和伸展兩個相位，中間有騰空。
- 肩胛隨步起伏，頭保持穩定看前方，尾巴反向擺動平衡。
- 新動作：撲擊（蹲、彈、伸爪）、爪擊、**貼面奔跑**（身體貼著斜面，第三項跑上巨人手臂用）。

**鶴**
- 翼由兩節改三節，初級飛羽成扇形展開，可以收攏。
- 拍翼分下撲（有力）和上收（摺起）；滑翔時壓翼轉彎；降落時仰身伸腿。
- 頸在飛行時縮成 S 形，俯衝時收翼伸頸。

**鯉**
- 脊柱由五節加到七節，轉彎時身體側傾。
- 胸鰭負責轉向，尾鰭成扇，加鬚。
- 新動作：**躍出霧面**（拋物線，帶起一道霧）。

### 驗收
- `?demo=shift`：三種化獸各做一次進入、5 秒活動、出招變回。
- 檢查：滿墨化獸時間 5.0 秒正負一幀；過渡期間速度連續（前後一幀速度差少於 10%）；墨量不足時再按不會化獸；人形 8 秒回滿。

## 三、巨相撲鬼：迫力與登頂擊殺

### 首次出場（約 6 秒，可按鍵跳過）

1. 第四個墨影化墨後，風停，霧向兩邊退開。
2. 鏡頭離開玩家肩後，貼地向前推到土丘前。
3. 土丘睜開紅眼。鏡頭由腳邊仰起跟著它站起來，視角由 50 度拉闊到 62 度，畫面微微傾斜。
4. 它的頭頂穿出霧面，霧從肩上瀉下。
5. 直書毛筆大字「巨相撲鬼」連朱印拍在畫面一側，全畫面閃白一幀。
6. 它踏下四股，震波掃過，鏡頭被震回玩家肩後，交還操作。

上下加水墨筆觸的黑邊。

### 攻擊的漫畫線

在最後合成那一步加一層畫面空間的墨線，三種：

- **集中線**（蓄力時）：由畫面四周指向舉起的手或腳，逐漸變密，告訴玩家危險在哪。
- **放射線**（命中一刻）：由落點向外爆開，兩幀內出現，0.25 秒內收回；同時全畫面黑白反轉一幀。
- **斜線**（巨掌下落的 0.2 秒）：沿手掌移動方向的平行斜線掃過畫面。

另外：
- **落點墨漬**：巨掌瞄準時地上有一灘墨慢慢擴大，讓玩家知道要離開哪裡。
- **鏡頭**：四股蓄力時鏡頭壓低仰視；巨掌舉起時鏡頭急速拉遠拉高；命中時停 3 幀再震。
- **環境**：震波經過時松樹搖晃、掉針；落點揚起霧牆。
- 可選：命中時在落點旁蓋一個毛筆擬聲字（例如「轟」）。

新增兩招讓節奏有變化：
- **突進**：相撲立合式衝過整片空地，要化鶴越過。
- **掃掌**：貼地橫掃，要跳或化鯉潛過。

### 登頂擊殺

巨人高 10.5 米，人跳不上去，必須連續化獸。主路線：

1. **引它出掌**，閃開。手掌貼地時斬一刀，它僵直，手臂貼地時間由 1.7 秒延長到 3 秒。
2. **向手掌翻滾，滾中再按＝化虎**。虎踏上手掌後自動貼著手臂跑：手掌 → 前臂 → 上臂 → 肩，約 0.6 秒。
3. **在肩上起跳，空中再按跳＝化鶴**。鶴向上飛過頭頂，途中它會用另一隻手拍你，要側飛閃開。
4. **在頭頂上方按攻擊＝變回人形下突刺**，刀插入頭頂。

整個過程要在兩次 5 秒內完成，所以要連貫，不能停。

另外兩條路線，讓三種獸都有用：
- **石柱**：空地邊那根 9.5 米石柱，化虎沿柱身跑上去，在柱頂化鶴滑翔到頭頂。
- **鯉躍龍門**：四股震波會把霧掀起一道柱。化鯉潛在落點附近，被霧柱帶著躍出霧面約 6 米高，空中化鶴接上。

**擊殺演出**：刀入頭頂時慢動作，鏡頭繞一圈；墨從頭頂噴出；紅眼熄滅；它搖晃、倒下、地面一震；身體化成一大片墨被霧吸走；霧散開，朱印「化墨」蓋下，切片結束。

切片內一刀擊殺（已定）。

### 需要的技術
- 巨人身體表面可以站：手掌、前臂、上臂、肩、頭各是一個膠囊，玩家位置記成「在哪一節、沿長度多遠、繞了多少度」，每幀跟著骨骼更新。
- 鶴碰到巨人軀幹和頭會被推開。
- 頭頂判定：人形在頭頂上方 1.2 米半徑內、正在下落、按了攻擊。
- 巨人新狀態：僵直、甩臂、拍擊、突進、掃掌、倒下。
- 鏡頭：出場、登臂、擊殺三段軌道鏡頭。

### 驗收
- `?demo=climb`：腳本跑完主路線並擊殺。
- 檢查：從斬手到插刀的總時間；貼臂奔跑時虎腳離手臂表面少於 10 厘米；三條路線各自能到達頭頂。
